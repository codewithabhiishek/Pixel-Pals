# 🐾 Pixel Pals: Adventure Run

> A vibrant, fast-paced retro-modern 2D animal platformer built with HTML5 Canvas, TypeScript, React, and procedural Web Audio API.

![Pixel Pals Banner](public/favicon.svg)

---

## 🌟 Overview

**Pixel Pals: Adventure Run** is a love letter to classic 16-bit platformers (like *Super Mario World* and *Sonic the Hedgehog*). Traverse 5 distinct handcrafted worlds, stomp enemies, discover secret pipes and bricks, collect coins, and take down **Magmor, the Ember King**!

### 🎮 Playable Heroes Roster
Choose from 4 unique animal companions, each with their own physics profile and stats:
- **Ember (Fox)**: The balanced trailblazer — no weaknesses, all heart.
- **Bramble (Bear)**: High endurance — starts with extra life and rolling power.
- **Pip (Frog)**: High jumper — clearing massive gaps and reaching sky secrets.
- **Zip (Hare)**: Blistering speed — top running speed for speedrunners.

---

## 🗺️ 5 Handcrafted Worlds
1. **Meadowlands**: Lush rolling hills, floating blocks, and gentle breezes.
2. **Crystal Caverns**: Underground tunnels, glowing stalactites, and falling hazards.
3. **Sunbaked Dunes**: Quicksand pits, desert winds, and high stone pillars.
4. **Frostbite Peaks**: Slippery icy surfaces and vertical climbing challenges.
5. **The Molten Forge**: Magma flows, falling fireballs, and the final showdown with **Magmor**.

## 🕹️ Controls

| Action | Keyboard |
| :--- | :--- |
| **Move** | `←` / `→` or `A` / `D` |
| **Jump** (Hold for height) | `SPACE` or `Z` |
| **Run / Dash** | `SHIFT` or `X` |
| **Drop Through Planks** | `↓` + `Jump` |
| **Pause Game** | `ESC` or `P` |

*Touch controls are automatically enabled on mobile and tablet devices.*

---

## 🚀 Tech Stack
- **Framework**: React 18 + TypeScript + Vite
- **Rendering**: HTML5 2D Canvas with sub-pixel interpolation & custom parallax engine
- **Styling**: Tailwind CSS v4
- **Audio**: 100% Procedural Web Audio API synthesizer (no external audio files required)

## 🛠️ Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/codewithabhiishek/Pixel-Pals-Adventure-Run.git

# Navigate into project directory
cd Pixel-Pals-Adventure-Run

# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
